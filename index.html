Política de Privacidade

SEI TJBA — Assistente Inteligente

📅 Última atualização: 18/08/2026 👤 Responsável: Anderson Brito ✉️ tiobred@gmail.com

Esta Política de Privacidade descreve detalhadamente como a extensão SEI TJBA Assistente Inteligente coleta, usa, processa, armazena e compartilha os dados do usuário, em conformidade com as Políticas do Programa para Desenvolvedores da Chrome Web Store e com a LGPD (Lei nº 13.709/2018).

Escopo: Esta extensão funciona exclusivamente no domínio *.tjba.jus.br e destina-se a servidores do Tribunal de Justiça da Bahia que utilizam o SEI.

1. Identificação do Responsável

  • Extensão: SEI TJBA Assistente Inteligente
  • Desenvolvedor: Anderson Brito
  • Contato: tiobred@gmail.com
  • Finalidade: Auxiliar na classificação de responsáveis, geração de resumos e controle de prazos no SEI/TJBA via IA.

2. Quais Dados São Coletados

2.1 Dados lidos da página do SEI (aba ativa)

  • Metadados do processo: número, tipo, especificação, assunto, interessados, unidade, marcadores.
  • Conteúdo textual dos documentos: texto de despachos, ofícios, certidões selecionados pelo usuário. Podem conter dados pessoais de partes, advogados e servidores.

2.2 Dados de configuração fornecidos pelo usuário

  • Provedor de IA escolhido (OpenAI, Gemini, Claude, OpenRouter, Ollama, etc.).
  • Chave de API do provedor de IA.
  • URL/endpoint do banco Supabase da unidade.
  • Regras de classificação e lista de responsáveis.

2.3 Dados de autenticação

  • E-mail e token de sessão para login no banco Supabase da unidade.

2.4 O que NÃO é coletado

A extensão não coleta: histórico de navegação, dados de outras abas, senhas do navegador, informações financeiras, localização, nem qualquer dado fora do domínio *.tjba.jus.br.

3. Como os Dados São Usados

Os dados são usados exclusivamente para as finalidades abaixo:

DadoFinalidade de uso
Metadados do processoPreencher formulário de classificação; salvar registro no banco da unidade.
Conteúdo dos documentosEnviar ao provedor de IA para sugerir responsável e gerar resumo analítico.
Chave de APIAutenticar chamadas ao provedor de IA configurado.
E-mail / token de sessãoAutenticar o usuário no banco Supabase da unidade.
Classificações e prazosArmazenar histórico e permitir painel de métricas compartilhado.
A extensão não usa dados para: publicidade, rastreamento, criação de perfis, venda a terceiros ou qualquer finalidade alheia à gestão de processos no SEI/TJBA.

4. Como os Dados São Processados e Armazenados

4.1 Armazenamento local (chrome.storage.local)

  • Configurações (provedor, endpoint, regras, responsáveis, limite de prazo).
  • Token de sessão do Supabase.
  • Cache de resumos gerados.

Esses dados permanecem até o usuário limpá-los ou desinstalar a extensão. Não saem do dispositivo por ação da extensão.

4.2 Banco de dados Supabase da unidade (servidor externo)

Metadados, classificações, prazos e resumos são gravados no banco Supabase configurado e operado pela unidade do TJBA (instância padrão: supabase.bredpizza.com.br). Comunicação via HTTPS/TLS. Dados permanecem até a unidade/administrador removê-los.

4.3 Provedor de IA (terceiro escolhido pelo usuário)

O conteúdo textual dos documentos é transmitido ao provedor de IA configurado para gerar sugestão de responsável e resumo.

  • Com Ollama ou Chrome Built-in AI: processamento local, conteúdo não sai do dispositivo. Local
  • Com provedor externo: transmitido conforme a política desse provedor (ver seção 5).

6. Base Legal para o Tratamento (LGPD)

O tratamento dos dados fundamenta-se no legítimo interesse do controlador (unidade do TJBA) na gestão eficiente de processos, e no consentimento do usuário ao utilizar voluntariamente a extensão (art. 7º, II e IX da Lei 13.709/2018).

8. Segurança

  • Toda comunicação com Supabase e provedores de IA externos ocorre sobre TLS/HTTPS.
  • Chaves de API ficam exclusivamente no chrome.storage.local do dispositivo e não são transmitidas ao desenvolvedor.
  • O banco Supabase exige autenticação por sessão para qualquer operação.

9. Controle do Usuário

  • Escolher Ollama ou Chrome Built-in AI para processamento 100% local.
  • Alterar ou remover configuração do Supabase nas opções da extensão.
  • Encerrar sessão pelo painel da extensão.
  • Remover dados locais via chrome://extensions → Detalhes → Limpar dados ou desinstalando.
