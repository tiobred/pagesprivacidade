Privacy Policy / Política de Privacidade

SEI TJBA — Assistente Inteligente

📅 Last updated: 20/08/2026 👤 Developer: Anderson Brito ✉️ tiobred@gmail.com

Summary (English)

SEI TJBA Assistente Inteligente is a productivity extension for the Brazilian Judiciary (Tribunal de Justiça da Bahia). It only operates on *.tjba.jus.br domains.

Data collected: Process metadata and document text from the SEI system pages (active tab only), user-provided configuration (AI provider, API key), and authentication credentials (email/session token for Supabase).

Data usage: Document text is sent to the user-configured AI provider (OpenAI, Google Gemini, Anthropic Claude, OpenRouter, or local models like Ollama) solely to classify the responsible officer and generate an analytical summary. Metadata, classifications, and deadlines are stored in a Supabase database operated by the user's organizational unit.

Data sharing: Data is shared only with (1) the user-configured AI provider and (2) the unit's Supabase database. The developer does not receive, store, or have access to any user data. No data is sold, used for advertising, or used for any purpose unrelated to the extension's core functionality.

Data retention: Local data (chrome.storage.local) persists until the user clears it or uninstalls. Supabase data persists until deleted by the unit administrator. AI providers process data according to their own retention policies.

Chrome Web Store User Data Policy Compliance: The use and transfer of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Esta Política de Privacidade descreve detalhadamente como a extensão SEI TJBA Assistente Inteligente coleta, usa, processa, armazena e compartilha os dados do usuário, em conformidade com as Políticas do Programa para Desenvolvedores da Chrome Web Store, incluindo os requisitos de Uso Limitado (Limited Use), e com a LGPD (Lei nº 13.709/2018).

Escopo: Esta extensão funciona exclusivamente no domínio *.tjba.jus.br e destina-se a servidores do Tribunal de Justiça da Bahia que utilizam o SEI.

2. Quais Dados São Coletados

A extensão coleta apenas os dados estritamente necessários para sua finalidade única. A coleta só acontece em páginas do domínio *.tjba.jus.br.

2.1 Conteúdo do site (Website Content)

  • Metadados do processo: número, tipo, especificação, assunto, interessados, unidade geradora, marcadores de controle.
  • Conteúdo textual dos documentos: texto de despachos, ofícios, certidões e demais peças processais selecionadas pelo usuário para análise. Esses documentos podem conter dados pessoais (nomes, CPFs, endereços) de partes, advogados e servidores.

2.2 Informações pessoais (Personally Identifiable Information)

  • E-mail: informado pelo usuário para autenticação no banco de dados da unidade (Supabase).
  • Token de sessão: gerado automaticamente pelo sistema de autenticação do Supabase.

2.3 Dados de configuração fornecidos pelo usuário

  • Provedor de IA escolhido (OpenAI, Google Gemini, Anthropic Claude, OpenRouter, Ollama, Chrome Built-in AI).
  • Chave de API do provedor de IA (informada manualmente pelo usuário).
  • URL/endpoint do banco de dados Supabase da unidade.
  • Regras de classificação, lista de responsáveis e limites de prazo definidos pelo gestor.

2.4 O que NÃO é coletado

A extensão não coleta, acessa ou processa:

  • Histórico de navegação
  • Dados de outras abas ou janelas do navegador
  • Senhas ou credenciais do navegador
  • Informações financeiras ou de pagamento
  • Dados de localização (GPS ou IP)
  • Comunicações pessoais (e-mails, mensagens)
  • Dados de saúde
  • Qualquer dado fora do domínio *.tjba.jus.br

4. Como os Dados São Processados e Armazenados

4.1 Armazenamento local no dispositivo (chrome.storage.local)

Os seguintes dados ficam armazenados exclusivamente no navegador do usuário e não são transmitidos ao desenvolvedor:

  • Configurações da extensão (provedor de IA, endpoint, regras do gestor, lista de responsáveis, limite de prazo).
  • Chave de API do provedor de IA.
  • Token de sessão do Supabase.
  • Cache de resumos gerados por IA (para evitar reprocessamento).

4.2 Banco de dados Supabase da unidade (servidor externo)

Os seguintes dados são transmitidos e armazenados no banco Supabase configurado e operado pela unidade do TJBA (instância padrão: supabase.bredpizza.com.br):

  • Metadados do processo (número, tipo, interessados).
  • Classificação sugerida e/ou confirmada pelo usuário.
  • Prazos definidos.
  • Resumo analítico gerado por IA.
  • Histórico de classificações (aprendizado).

O banco é compartilhado entre os servidores da mesma unidade. Toda comunicação ocorre via HTTPS/TLS.

4.3 Provedor de Inteligência Artificial (terceiro escolhido pelo usuário)

O conteúdo textual dos documentos selecionados é transmitido diretamente do navegador do usuário ao provedor de IA configurado, para gerar a sugestão de responsável e o resumo analítico. O desenvolvedor da extensão não atua como intermediário nessa comunicação.

  • Se o usuário escolher Ollama ou Chrome Built-in AI (modelos locais), o conteúdo é processado inteiramente no dispositivo e não sai da máquina. Local
  • Se o usuário escolher um provedor externo (OpenAI, Google Gemini, Anthropic Claude, OpenRouter), o conteúdo é transmitido ao provedor conforme a política de privacidade desse provedor (ver seção 5).

11. Security / Segurança

  • All communication with the Supabase database and external AI providers uses TLS/HTTPS encryption.
  • API keys are stored exclusively in chrome.storage.local on the user's device and are never transmitted to the developer.
  • The Supabase database requires session-based authentication for all read and write operations.
  • The extension follows the principle of least privilege — it only requests the minimum permissions necessary for its functionality.
  • No remote code is executed. All JavaScript runs from the bundled extension package.

12. User Control / Controle do Usuário

The user can, at any time:

  • Choose Ollama or Chrome Built-in AI for 100% local processing (no data leaves the device).
  • Change or remove the Supabase database configuration in the extension options.
  • End the authentication session via the extension panel.
  • Clear all local data via chrome://extensions → Extension Details → Clear Data.
  • Uninstall the extension at any time to remove all local data.
